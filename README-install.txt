KPC Guide — offline app (PWA)
1. Host this folder on any HTTPS web server (or open index.html directly for a plain offline copy).
2. Open the URL in Chrome/Edge/Safari → "Add to Home Screen" / "Install app".
3. After the first load the guide works fully offline; updates install automatically when a new version is hosted.
